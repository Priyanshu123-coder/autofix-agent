Model Context Protocol (MCP) Schemas

Standardized tool contracts exposed for TrueForge agent discovery and sandboxed invocation.

tool: github_fetch_ci_logs
Fetches structured CI/CD failure logs for a given GitHub Actions workflow run ID.
params: { runId: string, repo?: string }
tool: sandbox_reproduce_test
Executes a test script inside an isolated sandbox container to confirm failures.
params: { testPath: string, timeoutMs: number }
tool: sandbox_apply_patch
Applies a code modification to a target source file in the isolated sandbox.
params: { filePath: string, content: string }
tool: governance_request_human_approval
Triggers TrueForge human-in-the-loop approval gate before remote git push.
params: { action: string, diff: string }
