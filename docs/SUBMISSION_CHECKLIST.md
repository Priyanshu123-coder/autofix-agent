# 🏆 Hackathon Submission Checklist

Before submitting to WeMakeDevs / Devpost / Form, verify every item below:

- [ ] **Public GitHub Repository:** Created and accessible.
- [ ] **TrueForge Harness Utilized:** Code demonstrates harness runtime, sandboxing, and approval gates.
- [ ] **Qodo PR Review Evidence:** Public link to at least 1 Pull Request reviewed by Qodo (`qodo-merge` / PR-Agent).
- [ ] **2-Minute Demo Video:** Uploaded (YouTube / Loom / Vimeo) following `docs/DEMO_SCRIPT.md`.
- [ ] **Field Report Blog Post:** Published on Dev.to / Medium / Hashnode following `docs/FIELD_REPORT.md`.
- [ ] **README.md:** Clean, polished overview with architecture diagram and setup instructions.
